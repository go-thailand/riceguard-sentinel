# RiceGuard Sentinel — Website (Plain HTML/CSS/JS)

แปลงจาก template ต้นฉบับ (ดร.Cherry) ที่เป็นไฟล์ bundle ของ proprietary
templating engine ให้เป็น HTML/CSS/JS ธรรมดา ไม่มี framework ผูกอยู่
พร้อมใช้เป็น repo กลางให้ทีมต่อยอด

## วิธีเปิดดู
เปิด `index.html` ในเบราว์เซอร์ได้ตรงๆ (เป็น static site ไม่ต้อง build/server)

## โครงสร้างไฟล์
```
index.html
css/
  style.css     — design tokens (สี/spacing/font) + component classes (.card .btn .tag ฯลฯ)
  layout.css    — layout เฉพาะของเว็บนี้ (nav, hero, grid แต่ละ section, media query)
js/
  lang-data.js  — dictionary คำแปล 3 ภาษา (th/en/zh) ต่อ key
  main.js       — เมนูมือถือ (hamburger) + ตัวสลับภาษา
assets/
  img/          — รูปทั้งหมด, optimize แล้ว (WebP + PNG เดียวสำหรับโลโก้)
  icons/        — SVG ต้นฉบับจาก lucide-static เผื่อต้องแก้ไอคอนเพิ่ม (ในหน้าเว็บ inline SVG ไว้แล้ว ไม่ได้โหลดจากตรงนี้)
```

## สิ่งที่ทำไปตามใบงาน

**1. แตก template ออกมาเป็นโครงจริง** — decode bundler manifest, แยก
HTML/CSS/รูปเป็นไฟล์จริง, ลบ `<x-dc>`, `sc-for`, `sc-if`, `{{ }}` ทั้งหมด
(loop ข้อมูล heroStats/pipeline/deviceSpecs/pestTools/kbTiers/greenStats/
trialStats ถูกแปลงเป็น static HTML จริงแล้ว ไม่ใช่ loop syntax ที่ต้องมี
JS runtime มาช่วย render)

**2. ลบขยะ AI** — `{{ t.th }}` และ `{{ setTH }}` (ปุ่ม "ไทย" bind กับ
setter ที่ไม่เกี่ยวข้องเลย) ลบออกหมด ไม่มีหลงเหลือ (เช็คด้วย script แล้ว)

**3. เมนูมือถือ — สร้างใหม่ทั้งหมด** ตามที่ระบุว่าไม่มีของเดิมให้ลอก:
ปุ่ม hamburger, slide-in panel จากขวา, backdrop, ปิดเมื่อกด link/resize จอ
ทดสอบแล้วด้วย headless render (ดู mobile menu ทำงานจริง)

**4. Asset — บีบไฟล์แล้ว**
- โลโก้: 1.76MB → **15.9KB** (export ใหม่ที่ขนาดที่ใช้จริง ~150px แทน 1892px)
- รูปอื่นๆ: resize + แปลงเป็น WebP ตามขนาดที่แสดงจริงในแต่ละ section
- **น้ำหนักหน้าเว็บรวมทั้งหมด (HTML+CSS+JS+รูป) ≈ 560KB** (ไม่รวมฟอนต์ที่โหลดจาก Google Fonts) — ผ่านเกณฑ์ไม่เกิน 1MB
- ฟอนต์ Caprasimo, Figtree → ลิงก์จาก Google Fonts แล้ว (ไม่ฝัง base64)
  - เพิ่มเติม: Noto Sans/Serif Thai ที่เดิมฝัง base64 ไว้แต่**ไม่ได้ต่อเข้ากับ font-family ไหนเลย** (bug ของเดิม, โหลดมาเปล่าประโยชน์) ก็ย้ายไป Google Fonts และต่อเข้ากับ `--font-heading`/`--font-body` ให้ถูกต้องด้วย
- ไอคอน: ดึงมาเฉพาะ 25 ตัวที่ใช้จริงจาก lucide-static, inline เป็น SVG ตรงในหน้า (ไม่โหลด icon library ทั้งชุด)

**5. สีของ design system CSS 23KB ที่ย้ายมา — แก้ไขแล้ว**
ไฟล์ CSS ต้นฉบับมีตัวแปรสี `--color-accent` / `--color-accent-2` เป็นสี
ส้ม/เขียวมะกอกทั่วไป (ของ starter template) **ไม่ใช่สี CI ของ RiceGuard**
— ปุ่ม/ลิงก์ทุกจุดที่ใช้ class เหล่านี้เดิมต้อง override สีทับด้วย inline
style ทุกครั้ง (เห็นได้จาก `class="btn btn-primary" style="background:#8FB43A..."`)
ผมแก้ตัวแปรให้เป็นสีเขียว/ทองของ RiceGuard ตรงตามที่ใช้จริงทั้งเว็บแล้ว
(อ้างจากสีที่ AI ใช้สม่ำเสมอทั้งไฟล์: เขียว #5A7326/#8FB43A, ทอง #A67C00/#C9A227,
ครีม #F5EAD8, เข้ม #201E1D) **⚠️ รอ P'Kwang/ทีมช่วยเทียบกับไฟล์ CI Color
ตัวจริงใน Drive อีกรอบ** เผื่อมีสีที่คลาดเคลื่อนเล็กน้อย เพราะผมไม่มีไฟล์นั้น
ตรงมือ

## ระบบสลับภาษา (มติประชุม 4 ส.ค.)

สร้าง scaffold จริงแล้ว ทำงานได้ (ทดสอบกดสลับ EN/ไทย/中文 แล้ว state
เปลี่ยนถูกต้อง): ปุ่มในนำใช้ ไทย/EN/中文 ผูกกับ `js/main.js` ซึ่งอ่าน
dictionary จาก `js/lang-data.js`

**สถานะคำแปล:** ตอนนี้ EN และ 中文 ใน `lang-data.js` = ข้อความไทย
เหมือนกันหมด (ตามที่สั่งไว้ "ใช้ข้อความไทยไปพลาง") รอไฟล์จากเบส
(RIC-444) — พอได้มาแล้ว **แก้แค่ค่า `en`/`zh` ใน `js/lang-data.js`
ไม่ต้องแตะ HTML เลย**

**หมายเหตุสำคัญ:** เนื้อหาหลักของแต่ละ section (หัวข้อใหญ่ + คำบรรยาย)
เดิมออกแบบให้โชว์ "ไทย + อังกฤษ" คู่กันตลอดเวลาอยู่แล้ว (ไม่ใช่สลับ
ทีละภาษา) — ผมคงพฤติกรรมนี้ไว้ตามเดิม เพราะเป็นการออกแบบที่จงใจ
(bilingual display) ส่วนตัวสลับภาษาจริงที่ผมต่อ data-i18n ให้คือ: nav,
hero, หัวข้อ/คำอธิบายหลักของทั้ง 11 section, ปุ่ม, footer — รวม 82 keys
**ถ้าต้องการให้สลับทั้งหน้าแทนการโชว์คู่ ต้องคุยกับ P'Kwang ก่อนว่าจะ
เปลี่ยน design เป็นแบบนั้นเลยไหม เพราะเป็นการเปลี่ยนดีไซน์ที่มากกว่า
"ทำโครงสลับภาษา" เฉยๆ**

## สิ่งที่ยังเป็น placeholder (ของเดิมที่ต้นฉบับทำเป็น draft ไว้ ไม่ใช่งานที่ผมลืมทำ)

หลาย section มีข้อความ `<em>[เนื้อหาจริง: ...]</em>` เป็นตัวเอียงสีจาง
ๆ บอกไว้ว่ายังรอเนื้อหา/กราฟ/ตารางจริง (Gen 3→Gen 4 timeline, pest
dataset counter, ตารางเปรียบเทียบแปลงทดลอง, รายชื่อ 12 จังหวัด) —
นี่คือ placeholder ที่ต้นฉบับจงใจทำเป็น draft ไว้ตั้งแต่ต้น ไม่เกี่ยวกับ
งาน unpack/cleanup รอบนี้ ควรคุยกับ ดร.Cherry ว่าจะใส่เนื้อหาจริงตอนไหน

## เทคนิคที่ใช้ (สำหรับคนต่องาน)

- ไม่มี framework/build step — เปิดไฟล์ตรงๆ ได้เลย
- Grid layout ใช้ CSS Grid มาตรฐาน — ต้องเปิดดูบนเบราว์เซอร์ปัจจุบัน
  (Chrome/Safari/Firefox/Edge เวอร์ชันปี 2017+) ถึงจะเห็น layout
  หลายคอลัมน์ถูกต้อง (เครื่องมือ preview อัตโนมัติบางตัวที่ผมใช้เช็ค
  ระหว่างทำ เป็น engine เก่าที่ไม่รองรับ CSS Grid เลย แสดงเป็นคอลัมน์
  เดียวทั้งหมด — เป็นแค่ข้อจำกัดของเครื่องมือเช็ค ไม่ใช่ของเว็บจริง)
