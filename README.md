# RiceGuard Sentinel — Website (Multilingual)

เว็บไซต์แนะนำโครงการ **RiceGuard Sentinel** — งานวิจัยและพัฒนาเกษตรอัจฉริยะเพื่อชาวนาไทย
โดย **บริษัท โมบาย เอไอ จำกัด (Mobile AI Co., Ltd.)**

รีโพนี้เก็บหน้าเว็บเวอร์ชันภาษาต่าง ๆ ในรูปแบบ **ไฟล์ HTML ไฟล์เดียวจบ** (self-contained)
เปิดได้ทันทีด้วยเบราว์เซอร์ ไม่ต้องต่ออินเทอร์เน็ต ไม่ต้องติดตั้งอะไรเพิ่ม

## ▶️ วิธีเปิด / How to view

ดับเบิลคลิกไฟล์ `.html` ได้เลย หรือลากไปวางในเบราว์เซอร์ (Chrome / Edge / Firefox / Safari)

- ✅ เปิดแบบออฟไลน์ได้ 100% — รูปภาพ ฟอนต์ และโค้ดทั้งหมดฝังอยู่ในไฟล์
- ✅ ส่งต่อไฟล์เดียว (เมล / USB / แชท) แล้วเปิดได้เหมือนเดิมทุกเครื่อง ทุก OS
- ℹ️ หน้าเว็บใช้ JavaScript เรนเดอร์ (React) — ต้องเปิดในเบราว์เซอร์ ไม่ใช่โปรแกรมแก้ข้อความ

---

## 🌐 แนวทางการแปล / Translation approach

ต้นฉบับออกแบบเป็น **สองภาษา** (หัวข้อไทยตัวใหญ่ + อังกฤษกำกับตัวเล็กสีทอง)
เวอร์ชันแปลทำเป็น **ภาษาเดียวล้วน (monolingual)** เพื่อความสะอาดและเป็นมืออาชีพ:

- แทนที่เนื้อหาไทยด้วยภาษาเป้าหมายทั้งหมด
- ตัดบรรทัดกำกับที่ซ้ำกับหัวข้อออก (ยุบข้อมูลสำคัญขึ้นไปไว้ในหัวข้อแทน)
- ปุ่มสลับภาษาบนแถบเมนูไฮไลต์ภาษาของไฟล์นั้น ๆ (EN / 中文)
- เวอร์ชันจีนใช้คำศัพท์มาตรฐานจีนแผ่นดินใหญ่ (เช่น 边缘计算, 传感)
- ลบหมายเหตุงานที่ยังไม่เสร็จในวงเล็บเหลี่ยม (`[Space reserved…]`) ออกทั้งหมด

## 🔤 ฟอนต์ภาษาจีน / Embedded Chinese fonts

เวอร์ชันจีน (ZH) **ฝังฟอนต์จีนไว้ในไฟล์** (base64) จึงแสดงผลเหมือนกันทุกเครื่อง
แม้ปลายทางไม่มีฟอนต์จีนติดตั้ง:

| ฟอนต์ | น้ำหนัก | ใช้กับ |
|-------|---------|--------|
| **Noto Serif SC** | 400 / 700 | หัวข้อ (`.th`) |
| **Noto Sans SC** | 400 / 700 | เนื้อหา (`.thb` / body) |

- ผ่านการ **subset** เหลือเฉพาะ **402 ตัวอักษร** ที่หน้านี้ใช้จริง (รวม ~266 KB)
- License: **SIL Open Font License 1.1** — ฝังและแจกจ่ายได้ฟรี

> ⚠️ หากแก้ข้อความจีนเพิ่มด้วย **ตัวอักษรใหม่** ที่ไม่อยู่ใน 402 ตัวนี้
> ตัวใหม่จะไม่มีในฟอนต์ที่ฝัง (ต้อง subset ฟอนต์ใหม่)

## 🛠️ รายละเอียดทางเทคนิค / Technical notes

- ไฟล์เป็น **bundled single-file page**: โครง HTML + เฟรมเวิร์กเทมเพลต (`sc-for` / `{{ }}`) + React
  โดยรูปภาพ/ฟอนต์ทั้งหมดฝังเป็น base64 (ไม่มี asset ภายนอก)
- การแปลทำที่ระดับ **template** แล้วประกอบกลับเข้าโครง bundle เดิม
  → รูป ฟอนต์ สคริปต์ เลย์เอาต์ สี เหมือนต้นฉบับทุกอย่าง
- เนื้อหาแบบไดนามิก (การ์ดสถิติ / ไปป์ไลน์ / สเปกอุปกรณ์) แปลในดาต้าอาเรย์ภายในเทมเพลต
